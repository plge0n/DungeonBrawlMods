# 更新日志

## 0.41.0

- 说明写明和游戏 7.15 原版「自动锻造器」的分工：原版在商店批量做黄金锻造、不弹选择窗口；AutoForge 继续处理普通/黄金锻造器、英雄被动、Hextech 等弹出的三选一。两者不冲突，代码没有改动。
- 7.15 删掉了史诗锻造选择，史诗档的候选不会再出现。

## 0.40.0

- 首个版本：自动锻体，可按自定义属性权重选择，也可用均衡模式优先补足本局锻造提升较少的属性。候选全是权重 0 的属性时照常手选。
- F10 开关，在「Mod → AutoForge → 设置」里调整模式、权重和快捷键；选中后显示提示。不会自动购买锻造器。
- 联机只操作本机；经游戏作者同意，可以打榜。重试波次时，本局累计的锻造提升随进度恢复。
- **没有实机测试**，只检查编译和启动到主菜单；自动选择、联机和重试恢复仍需验证。
