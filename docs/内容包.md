# 内容包：不写代码做 Mod

内容包是一个文件夹：`dbmod.json` + 若干 JSON + 图片 + 翻译。DBModKit（0.21.0 起）直接加载，不需要 dll、不用逐个确认。
完整示例见 [templates/ContentPack](../templates/ContentPack)。
不想手写 JSON 可以用[内容包工作台](../tools/ContentWorkbench)：用 Edge 或 Chrome 打开 `tools/ContentWorkbench/index.html`，用表单编辑，边改边检查。

## 放在哪

| 位置 | 用途 |
|---|---|
| `BepInEx/content/<名字>/` | 本地制作、测试 |
| `BepInEx/workshop-dev/<名字>/` | 模拟创意工坊条目 |
| 创意工坊订阅 | 分发：`pwsh ./pack.ps1 -Content <文件夹>`（或放进仓库 `content/`）生成工坊条目 |

游戏启动时扫描一次；改了 JSON 后在 Mod 设置 → DBModKit → 内容包里"关闭"再"启用"就会重新读（战斗中不能切换）。

## dbmod.json

```json
{
  "Format": 1, "Type": "content",
  "Id": "author.thunder", "Name": "雷霆套装", "Author": "…", "Version": "1.0.0",
  "MinModKit": "0.21.0",
  "Content": ["skills.json"],
  "Lang": "lang"
}
```

- `Id`：**一定要写**，只用字母、数字和 `. _ - +`。技能编号由它和技能的 `key` 算出，联机时也按它比对。不写时用文件夹名，本地和工坊里的编号就会不一样。
- `Content`：要读的 JSON（相对这个文件夹）。
- `Lang`：翻译文件夹，`<语言>.json` 平铺键值，键是 `skill.<key>.name/desc`、`passive.<key>.name/desc`、`hero.<key>.name/desc`。
- `Dependencies`（可选）：依赖的插件或别的内容包，例如 `[{ "Guid": "author.base", "MinVersion": "1.0.0", "Workshop": 3800000000 }]`。
  依赖的包会先加载；缺了整个包不加载，Mod 设置里有"订阅"按钮。详见[依赖和冲突](api/依赖和冲突.md)。

## JSON 文件

顶层几个列表，键名区分大小写，**写了不认识的字段会报错**：

```json
{ "activeSkills": [ … ], "passiveSkills": [ … ], "relics": [ … ], "equipEffects": [ … ], "equipment": [ … ], "heroVariants": [ … ] }
```

### 主动技能

| 字段 | 说明 | 默认 |
|---|---|---|
| `key` | 包里唯一，只用英文字母、数字、下划线 | 必填 |
| `name` / `description` | 说明里 `{0}` 是游戏按伤害公式生成的文字（有 `values` 时换成数值） | `name` 必填 |
| `icon` | 游戏图标名（如 `SpellBook01_66`），或包里的图片 `assets/x.png` | `SpellBook01_66` |
| `quality` | D C B A S | C |
| `indicator` | None / Range / Vector / Target | Range |
| `cost` `cooldown` `castingRange` `range` | 蓝耗、冷却、施法距离、作用半径 | 20 / 8 / 8 / 3 |
| `duration` `interval` | 持续秒数（0 = 一次性）、说明里的伤害间隔 | 0 / 0 |
| `damageBase` `damageValue` `damageType` | 伤害公式：base + 属性 × value（0 攻击 1 力 2 敏 3 体 4 最大生命） | 0 |
| `charges` `chargeTime` `values` `canAuto` `inSkillBook` `tags` | 同 C# 的 `ActiveSkillDef` | |
| `animation` | `{ "game": "动作名", "speed": 1, "duration": 2 }`，释放时换动作 | |
| `onCast` / `onEnd` | 效果列表 | |
| `onTick` | `{ "every": 0.5, "do": [效果…] }`，需要 `duration` > 0 | |

### 被动

`key` `name` `description`（`{0}` 换成 `values`，含等级成长） `icon` `quality` `values` `levelUp` `inSkillBook` `repeatable` `tags`，
触发器：`onAdded` `onRemoved` `onHit`（本机造成的命中，`damage` = 伤害） `onKill` `onCrit` `onHurt`（`damage` = 掉的血）
`onWaveStart` `onCast`（自己放技能） `onTick`（`{ "every": 秒, "do": [...] }`）。

### 遗物

`key` `name` `description`（`{0}` 换成 `values`，含等级成长） `icon`（游戏遗物图标名，如 `remain_str`，或包里的图片） `quality`
`values` `levelUp` `valueTypes`（Normal / Percent / PercentConst / InversePercent） `maxLevel`（-1 不限） `unique`（默认 true） `inPool`（默认 true），
触发器和被动一样。升级时自动撤销 onAdded 里"跟着遗物走"的加成，再按新等级执行一次 onAdded。

```json
"relics": [{
  "key": "thunder_heart", "name": "雷霆之心", "description": "攻击力 +{0}；击杀敌人回复 {1} 点法力",
  "icon": "remain_str", "quality": "B", "values": [30, 5], "levelUp": [15, 2],
  "onAdded": [ { "addStats": { "attack": "{0}" } } ],
  "onKill":  [ { "mana": "{1}" } ]
}]
```

翻译键 `relic.<key>.name/desc`。

### 装备特效、装备

（0.24.0 新增，还没有在游戏里实测过。）

装备特效：`key` `name` `description`（`{0}` 换成 `values`，含强化成长） `values` `levelUp` `attachTo`（挂到哪些游戏装备上，写装备编号的列表，可以不写），
触发器和被动一样（`onAdded` 是穿上，`onRemoved` 是卖掉）。挂上后游戏装备的说明里会多出这个特效。

装备：`key` `name` `description` `icon`（游戏装备图标名，如 `equip_2`，或包里的图片） `attributes`（`{ "属性名": 数值 }`，属性名用装备表的，
如 `attack` `hp` `Armor` `attackSpeed` `STR` `skillDamage`，百分比类写小数） `effects`（同一个包里装备特效的 key） `gameEffects`（游戏特效名，如 `Sputtering`）
`artifact`（进神器三选一，默认 false）。至少要有属性或特效。**内容包里的装备只能从神器三选一拿到**（不进商店、不掉落），所以一般要写 `"artifact": true`。

```json
"equipEffects": [{
  "key": "static_edge", "name": "静电", "description": "命中时 {0}% 几率回复 {1} 点法力",
  "values": [20, 5], "attachTo": [2],
  "onHit": [ { "mana": "{1}", "chance": "{0}", "cooldown": 0.5 } ]
}],
"equipment": [{
  "key": "storm_staff", "name": "风暴法杖", "icon": "equip_2", "artifact": true,
  "attributes": { "attack": 60, "hp": 200 }, "effects": ["storm_charge"]
}]
```

翻译键 `equipEffect.<key>.name/desc`、`equip.<key>.name/desc`。

### 变体英雄

`key` `name` `description` `baseHero`（1~43），属性 `strength` `agility` `stamina` `strengthGrowth` `agilityGrowth` `staminaGrowth`
`attack` `armor` `hp` `mp` `hpRecover` `mpRecover` `moveSpeed` `attackSpeed`，专属技能四选一：`activeSkill` / `passiveSkill`（同一个包里的 key）、
`gameActiveSkill` / `gamePassiveSkill`（游戏编号），模型 `modelFolder`（包里的文件夹）或 `workshopModel`（工坊物品号）。

## 效果

每个效果是一个对象，写一种效果，再加可选的条件：

| 效果 | 写法 | 附加字段 |
|---|---|---|
| 伤害（只限主动技能） | `{ "damage": "area" }` / `"target"` | `scale`（乘公式伤害）、`amount`（直接给数值）、`radius` |
| 治疗 / 回蓝 | `{ "heal": 表达式 }` / `{ "mana": 表达式 }` | |
| 金币（只在单人时给） | `{ "gold": 表达式 }` | |
| 加属性 | `{ "addStats": { "str": …, "agi": …, "sta": …, "attack": … } }` | `seconds` |
| 攻速 / 护甲 | `{ "addAttackSpeed": 0.2 }` / `{ "addArmor": 10 }` | `seconds` |
| 特效 | `{ "effect": "Effect/SpellThunder" }` | `duration`、`scale`、`at`（position / self / target） |
| 换动作（只限主动技能） | `{ "animation": "动作名" }` | `speed`、`duration` |
| 屏幕提示 | `{ "notice": "文字，可以用 {0}" }` | `seconds` |

加属性类不写 `seconds` 时跟着技能走：主动技能结束时、被动、遗物或装备失去时自动撤销。

条件（任何效果都能加）：`chance`（百分比）、`hpBelow`（自己血量百分比）、`isBoss`（目标是不是 Boss）、`cooldown`（内部冷却秒数）。

**表达式**：数字，或文字形式的四则运算和括号，可以用 `{n}`（第 n 个数值）、`damage`、`hp`、`maxHp`、`mana`、`maxMana`、
`str`、`agi`、`sta`、`attack`、`level`、`wave`。例如 `"damage * {1} / 100"`。

## 联机

内容包里的技能、被动、遗物、装备、装备特效和改了属性的变体都算"改玩法的内容"，由 DBModKit 的联机握手决定能不能用：单人、房间里每个人都装了同样的包
（`Id`、版本、JSON 内容都一样）或房主允许时可用，否则不进技能书和三选一、装备特效不挂到游戏装备上、变体只换模型。

## 出错时

写错的条目整条跳过，同一个包里其他条目照常加载。错误显示在 Mod 设置 → DBModKit → 内容包，也写进 `BepInEx/DBModKit/trace.log`，
格式是"文件.列表[序号].字段：原因"，例如 `skills.json.activeSkills[1]：不认识的字段 "cooldwn"`。

## 暂不支持

- 线形伤害（`line`）、被动、遗物和装备特效里造成伤害、包里的 AssetBundle 特效和动作。
- 数值改动（改游戏的技能表、英雄表）：先用 DBStudio 的玩法包。
- 卡牌、怪物；自定义装备的强化。
