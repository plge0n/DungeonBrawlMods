# 自定义装备：实施计划

交给新对话直接开工。调研已经做完（静态阅读反编译代码，2026-10-22），结论也记在 `../tools/NOTES.md` 的"装备"一节。
用户的决定：**两种都做**——①给游戏已有的装备挂自定义特效；②全新装备。**卡牌先不做**（局外构筑、写进存档，卸载 Mod 后存档残留会让几处界面抛异常）。

## 做之前必读

- 分支 `feat/custom-equipment`，worktree `../_DungeonBrawl_mods_equip`（已经基于 main 7ce8583）。不动 main 的工作目录。版本 DBModKit **0.24.0**。
- 写法照抄自定义遗物（`DBModKit/Relics.cs`、`GameRaw` 里"自定义遗物"一节、`Hooks.RelicHooks`），它是同一套路：往原始表和类型化表加行 → 在"名字 → 子类"的 switch 上加后缀 → 在构筑数据上过滤。
- **注入表时空格子写 `""`，不要写 null**：游戏读表时空格子就是空字符串，按 `dwb<string>` 读的地方遇到 null 会空引用。0.23.1 就因为这个在联机出生时断线（见 CHANGELOG）。
- 混淆名只写在 `GameRaw.cs` / `Hooks.cs`，新用到的成员加进 `Compat.cs`（**同一个键不要写两次**，`bba`、`jy`、`ke` 这些可能已经有了，往原来那一条里加）。
- 改完跑 `dotnet run --project tools/Remap -c Release -- selftest --old ../backup/6.45 --mutate 0.03`；离线测试在 `../tools/tests/`（ContentTest 用反射调 `ContentReader.ReadFile`，签名变了要同步改测试）。
- 编译测试用 `-p:DeployToGame=false`；部署前看部署检查规则（README），别覆盖别的会话的版本。
- 在 Bash 里写含引号的多行 heredoc 容易解析失败：改代码先用 Write 写一个 .py 脚本再运行。用 sed 改 Windows 文件会去掉 CR。
- 实机测试用 `D:\Ai Tool\unity-mod\01-游戏内调试\DevBridge`：`ev.sh` 在运行中的游戏里执行 C# 片段（用 `Bridge.Out(...)` 输出，不能 `return`，不支持局部函数，`Time` 要写 `UnityEngine.Time`）。用户操作、你读 `BepInEx/DBModKit/trace.log`。

## 方案

### ① 自定义装备特效（挂到已有装备上）

```csharp
var thunder = mod.RegisterEquipEffect(new EquipEffectDef
{
    Key = "static", Name = "静电", Description = "攻击时 {0}% 概率…",
    Values = new[] { 20f }, LevelUp = new[] { 2f },
    AttachTo = new[] { 2, 3 },              // 游戏装备编号；空表示只给自定义装备用
    Create = () => new StaticCharge(),      // : EquipEffectBehaviour
});
```

- 编号：`SkillIds.Allocate(owner, key, 4000000, …)`，当成 `(EquipSkillType)编号`。
- 注入：`cx.zyc["equipmentSkill"]["<编号>"]` 加一行（模板行副本，kingLock = true，空格子 `""`）。
- 补丁：
  - `bba.khf` 后缀：编号是我们的 → `__2`（out ke）= `new ModEquipEffect(编号)`（`ke` 子类，像 `ModRelic` 那样用实例编号映射行为对象）。
  - `jy.Init(RoleType)` 后缀：不是 King、`Multiplayer.GameplayAllowed`、这件装备的编号在某个特效的 `AttachTo` 里 → `k9326(特效, values, levelUp)`。
- 行为 `EquipEffectBehaviour`：`Owner`、`Equipment`（装备编号）、`Level`（`bbcn`）、`Value(i)` = values[i] + levelUp[i] × 等级；
  `OnAdded`（Init）/ `OnRemoved`（Clear）/ `OnLevelChanged`（evl/evm）/ `OnUpdate`（euv）/ `OnGameEvent` / `OnHit`（ModKit 自己分发，只发给本地玩家装备上的）。
- 不需要过滤构筑数据：`ebg` 不序列化 `bayp`。说明文字：`etz` 读 `"equipSkill_<编号>_m"`，走现有的文本钩子（`GameRaw.SkillText`）。

### ② 全新装备

```csharp
mod.RegisterEquipment(new EquipmentDef
{
    Key = "storm_staff", Name = "风暴法杖", Description = "…", Icon = "equip_2",
    Attributes = { ["attack"] = 80, ["skillDamage"] = 0.1f },   // 键名用 jy.bayh 里的，注册时校验
    Effects = { thunder },                                       // 自定义特效（也可以写游戏的 EquipSkillType）
    Artifact = true,                                             // 进神器三选一
});
CustomEquipment.Give(info);                                      // 本地发放，装备栏满了返回 false
```

- 编号 `SkillIds.Allocate(owner, key, 5000000, …)`。
- 注入：`cx.zyc["equipment"]["<编号>"]`（模板行副本：attributeType/Value 按 Attributes 拼，skill 写第一个特效的编号字符串、skillValue/Up 写它的数值，
  其余特效靠①的 `jy.Init` 后缀追加；maxLevel = 0（第一版不做强化）、canTransmute = false、isArtifact、conflict/mapTypes/humanity 写 `""`）+ `oo.bcsl["<编号>"] = jy.erc(行)`。
- 发放：`pi.ghk("equip_<编号>")`，先检查 `bfmz.Count < nn.MaxEquipNum` 和 `GameplayAllowed`。
- 神器池：`Artifact = true` 时在原始表写 isArtifact = true，就会进 `pi.ghn` 的候选。联机握手不允许时要从池里去掉：给 `pi.gho` 加后缀（编号是我们的且 `!GameplayAllowed` → false）。
- **必须**给 `ez.ebg` 加后缀，去掉自定义装备（返回空数组时改成 null，和原版一致）。不然没装 Mod 的人打开构筑面板会空引用（bmy.cs:633），镜像 Boss 会拒绝"Unknown equipment"（bax.cs:724）。
- 出售：id > 100 读 `shop["equip_0"]` 的价格（bba.cs:1300 附近），先不管，实测时看卖出去会不会出错。
- **不要**让自定义装备掉在地上（装备不是地面物品，Boss 掉落是"道具 → 使用 → ghk"，要新增 ItemType，没装 Mod 的人一定出问题）。

### ③ 其余

- 联机握手：特效和装备的所有者计入 `Multiplayer.BuildSignature`。
- 内容包：`equipEffects`（触发器和被动一样，复用 `PassiveSpec`/效果库，实现 `ContentEquipEffect : EquipEffectBehaviour, IEffectHost`）和 `equipment`（attributes 对象、effects 写同一个包里的特效 key、artifact）。
- 示例：SkillSample 加一件装备 + 一个挂到已有装备上的特效；`templates/ContentPack` 加一件。
- 文档：`docs/api/装备.md`、README 对照表、`docs/内容包.md`、CHANGELOG 0.24.0。

## 验收（单人即可，联机部分最后测）

- 给已有装备（比如 2 号狂战斧）挂的特效：商店买到后特效生效，说明里有它；卖掉后 `OnRemoved` 被调用。
- `CustomEquipment.Give`：装备栏出现，属性加上，名字、说明、图标正常；装备栏满时返回 false。
- `Artifact = true` 的装备能在神器三选一里刷到，选了正常穿上。
- 构筑数据：DevBridge 里调 `ez.ebg()`，看不到自定义装备编号。
- 联机（要两人）：没装 Mod 的人打开你的构筑面板不报错；握手停用时神器池里没有自定义装备。
