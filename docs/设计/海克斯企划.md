## 一、定位

每个英雄开局自带一个专属技能（`hero` 表的 `skill` 列；`zhuDong` 为真是主动技能，否则是被动技能）。海克斯的每个强化**只改这一个技能**，让同一个英雄每局都能玩出不同的路子。

和其他系统的分工：属性书、装备、遗物、卡牌负责整体变强；海克斯只负责"专属技能怎么玩"。

## 二、范围

完整清单和参数见 `_DungeonBrawl_tools/diag/hero_skills.txt`。

| 类型 | 技能 / 英雄 | 第一期 |
|---|---|---|
| 主动技能 | 21 个技能（id 500–521，缺 515），22 个英雄（赛博剑圣和吉他英雄共用拔刀术） | **开** |
| 被动技能（有参数） | 11 个技能，11 个英雄（原始人、矮人学徒、电锯狂人、酒馆老板、黑暗领主、死灵祭司、电次、玛露西尔、乌萨奇、路飞、蓝羽炮手） | **开**，只用参数积木（见三.4） |
| 被动技能（没有参数） | 10 个（二刀流、鸡枪、死亡笔记……） | 不开，以后只能逐个手写 |

- 没开海克斯的英雄：海克斯回合不弹，游戏照常进行。
- 卡卡西偷来的技能、技能书学到的技能**都不算**专属技能，不受海克斯影响。
- **只做单人**：沿用 DBStudio 的联机策略，只在房间里只有自己时生效；有第二个人进房间就停用，已选的强化全部撤销。以后要做联机时，再考虑"房主勾选本局允许"那条路。
- 游戏原本的遗物三选一照常保留，海克斯是额外加的。
- 装了 Mod 不能上传排行榜（ModKit 已经强制拦截），海克斯不能绕过这条规则。

## 三、生成器

### 1. 流程

1. **读技能**：从 `activeSkill` 表读出参数（cd、cost、chargingNum、duration、damageBase / damageValue）和标签（tags）。
2. **筛积木**：只保留对这个技能有意义的积木（见下表的"出现条件"）。
3. **凑点数**：按品质预算（银 3 点、金 6 点、棱彩 10 点，允许误差 ±1）随机组合积木：
   - 银：只能用参数积木。
   - 金：最多 1 个触发效果积木。
   - 棱彩：最多 2 个触发效果积木，可以带 1 个代价积木（代价是负点数，等于用代价换更多效果）。
   - 同一张卡里同种积木不重复。
4. **生成名字和描述**：词头取自触发或代价，词根取自主要效果，例如"狂暴·回响：释放炸弹！后，0.5 秒后免费再放一次；冷却 +20%"。描述里写出算好的实际数值。
5. **种子**：一局固定一个种子，重试波次时抽到的卡和原来一样。

### 2. 积木表（初稿，点数和数值等实测后再调）

**参数积木**（改配置表里这个技能的那一行，可以叠加）

| 积木 | 效果 | 点数 | 出现条件 |
|---|---|---|---|
| 威力 | 伤害 +15% | 2 | damageValue 或 damageBase > 0，并且伤害真的读表（拔刀术 501、召唤祢豆子 507 写死在代码里，第一期不出） |
| 急速 | 冷却 -12% | 2 | cd ≥ 2 秒 |
| 节能 | 蓝耗 -35% | 1 | cost > 0 |
| 延时 | 持续 +25% | 2 | duration > 0 |
| 充能 | 充能 +1 | 4 | chargingNum > 0 |

**触发效果积木**（触发：释放专属技能时，或每第 3 次释放时；选后者效果 ×2.5）

| 积木 | 效果 | 点数 | 出现条件 |
|---|---|---|---|
| 战意 | 释放后 N 秒攻速 +25% | 2 | — |
| 疾风 | 释放后 N 秒移速 +20% | 1 | — |
| 铁壁 | 释放后 N 秒减伤 +20% | 2 | — |
| 无敌 | 释放后无敌 0.5 秒 | 3 | 技能本身不带无敌 |
| 回流 | 返还 30% 蓝耗 | 1 | cost > 0 |
| 汲取 | 回复 3% 生命上限 | 2 | — |
| 收割 | 技能击杀时返还 20% 冷却（每次释放最多触发一次） | 3 | 有伤害，cd ≥ 3 秒，并且伤害能归属到技能（拔刀术 501、演奏音乐 502、花式扣篮 509 归属不了，不出） |
| 回响 | 释放后 0.5 秒免费再放一次 | 5 | cd ≥ 3 秒；不是变身、形态切换、开关类（505、510、517），也不是技能窃取 508 |

**代价积木**（只用于棱彩）

| 积木 | 效果 | 点数 |
|---|---|---|
| 沉重 | 冷却 +20% | -2 |
| 贪婪 | 蓝耗 +50%（需要 cost > 0） | -1 |
| 献祭 | 生命上限 -15% | -3 |

### 3. 平衡规则

- **按冷却缩放**：buff 持续时间 N = 冷却 × 0.5，限制在 2–8 秒之间。冷却越长的技能，单次收益越大。
- **内置冷却**：触发效果最多每 max(技能冷却, 3 秒) 触发一次。防止形态切换（cd 1 秒）、翻滚（cd 1 秒）、炸弹（cd 0.5 秒、3 次充能）这类技能刷触发。
- **参数下限**：冷却最多减到原来的 40%，蓝耗最低 0。
- **特殊技能**：形态切换、技能窃取、制作蟹黄堡、我没有开挂这类没有伤害的技能，可抽的积木很少。抽不够三张时，用"触发效果"积木补齐。⚠ 要实测体验，如果太单调，就优先给它们写招牌。

### 4. 被动技能（有参数的 11 个）

被动技能没有统一的释放入口，所以没有触发效果积木，只用参数积木：

- **逐个标注**：每个技能在一份配置里手写一行，说明 value 的每一项是什么、"越大越好"还是"越小越好"、上限是多少。例如：
  - 起洞 `20|500|4`：概率（越大越好，上限 60）、基础伤害（越大越好）、力量倍率（越大越好）。
  - 电锯恶魔 `5|1.5|5`：目标最大血量百分比伤害（越大越好）、被普通敌人打时扣自己最大血量 %（越小越好）、被 Boss 打时扣自己最大血量 %（越小越好）。
  - 橡胶果实 `50`：**承受**伤害的比例（越小越好，下限 25）。

  第 0 期查到的完整含义（以代码为准，说明文字有好几处不对）：

  | id | 技能 | 各项含义 | 方向 / 限制 |
  |---|---|---|---|
  | 501 | 起洞 | 概率%、基础伤害、力量系数 | 都越大越好；概率上限 60 |
  | 502 | 量子阅读 | 学技能书时三围加成 | 越大越好；会四舍五入，每次至少 +1 |
  | 503 | 复仇电锯 | **死亡时**三围加成 | 越大越好 |
  | 504 | 内部折扣 | 商店**价格倍率%**（70 = 七折） | 越小越好，下限 30；必须在发放前改 |
  | 505 | 凝视黑暗 | 每 60 秒三围 +[0]×(波次+1) | 越大越好 |
  | 506 | 对死者的供奉 | 伤害 =（敏+力）×([0] + 等级×[1]) | 都越大越好 |
  | 511 | 电锯恶魔 | 见上 | 后两项下限 0.5；要改缓存字段 |
  | 513 | 禁忌魔法 | 主动技能升级概率% | 越大越好，上限 100；只对 id<400 的技能生效（专属技能不会被升级） |
  | 514 | 三级除草证 | 力量系数（同一目标第 3 次攻击爆炸） | 越大越好 |
  | 515 | 橡胶果实 | 承受伤害% | 越小越好，下限 25 |
  | 521 | 榴弹发射器 | 力量系数（每发命中都爆炸） | 越大越好 |
- **积木**：每个"越好"方向的参数生成一块积木（比如"概率 +5"、"力量倍率 +25%"），点数按标注的强度给。棱彩同样可以带代价积木。
- **单参数的技能**（量子阅读、复仇电锯、内部折扣、凝视黑暗、禁忌魔法、三级除草证、橡胶果实、榴弹发射器，共 8 个）只有一块积木，三张卡只能靠数值大小和代价区分，体验会比较单调，**是招牌棱彩的优先对象**。
- 读取时机（已查清）：value 在获得时拷进技能实例的 `bhnp`，多数被动每次触发都读它，直接改实例就行（实测起洞概率改 100 后每次普攻都打洞）。例外是 504（发放前改）和 511（改缓存字段）。

## 四、招牌棱彩（手写）

- 给最有特色的技能手写棱彩强化，做出生成器拼不出来的、只属于这个技能的玩法。
- 和生成的卡在同一个卡池；这个英雄抽棱彩时，招牌卡出现的权重 ×3。
- 不能重复获得。

## 五、一局的流程

| 次数 | 时机 | 品质 |
|---|---|---|
| 1 | 开局，紧接游戏自己的开局遗物选择 | 银 / 金 |
| 2 | 约 25% 波次附近的遗物回合 | 金为主 |
| 3 | 约 50% 波次附近的遗物回合 | 金 / 棱彩 |
| 4 | 约 75% 波次附近的遗物回合 | 棱彩为主 |

- 遗物回合由关卡配置决定（`enemySpawnData[i].eventList` 含 `Roguelike`），总波数是 `enemySpawnData.Length`。按比例挑最近的一个遗物回合，排在游戏的遗物三选一**之后**弹出。例如 20 波的图 → 开局、第 5、10、15/16 波前；50 波的图 → 开局、第 15、25、40 波前。
- 同一次三张卡品质相同（照 LoL）。
- 刷新：每局 2 次，整体刷新（游戏三选一界面自带），刷新时重新生成。
- 重试波次后，要恢复到那一波开始时的强化状态：游戏在休息阶段开始时拍快照（早于遗物选择），技能实例上的改动会跟着自动回滚；Mod 自己的记录（已选强化、种子、刷新次数）在 `wb.gyk` 时存一份，`wb.gym` 成功时恢复。重试后游戏会重弹这一波的遗物选择，海克斯也跟着重弹。
- HUD：专属技能图标上加一个角标，显示已选强化的数量；鼠标悬停列出各个强化。

## 六、实现思路（第 0 期结论，✓ 表示已在游戏里实测）

- **参数积木（主动）** ✓：不改全局配置表。Harmony 补丁挂在技能工厂 `ez.dzc` 上，施法者是本地玩家时临时换成改过的那份参数，放完立刻还原。实测闪烁伤害参数 ×10，伤害从 570 变成 5700，表里的值不变。
  - 扣蓝时游戏会重新查表（`ez.dye` / `ez.dyf`），改蓝耗时这两处也要包上临时替换。
  - 冷却、蓝耗、充能同时直接写技能实例 `bht` 上的字段（防篡改不查这些，游戏自己也这么写），下次释放就生效。
- **参数积木（被动）** ✓：直接改技能实例的 `bhnp` 数组（同时改 `bhnq`，防止升级时被覆盖），504、511 按三.4 特殊处理。
- **触发**：`localActiveSkillCastEvent` 带技能 id 和"是不是免费释放"标记，所有专属技能都会触发它。例外：形态切换（517）再按一次关闭时不触发；雷之一闪（521）连闪中再按不触发；技能窃取（508）偷来的技能上报的是被偷技能的 id，不算专属技能。
- **回响** ✓：用游戏自带的免费释放 `ez.dyf(..., h: true)`（游戏自己的被动"长老的多重施法"就是这么做的）。实测不扣蓝、不进冷却；会再次触发释放事件，但带"免费"标记，靠它防止回响套回响。
- **技能击杀** ✓（部分）：在受伤方法 `yb.iwk` 上挂补丁，按受害者记录"最近一次命中来自哪个技能"（实测闪烁命中带 `bfe=Hero_Blink`）；击杀事件触发时查这条记录。拔刀术、演奏音乐、花式扣篮归属不了；召唤物的击杀归属还没测。
- **限时 buff**：`roleBuffManager.mim<T>`。
- **出现时机**：复用 DBStudio 强化页的做法，每帧检查三选一界面是否忙，空闲 1.5 秒后再弹。DBStudio 没做开局那一次，要补上。
- **单人**：用 `DBModKit.Game.IsSolo` 每帧判断，从单人变成多人的那一帧撤销所有强化。
- **英雄生命周期**：每局开始英雄会被重新初始化（对象可能复用），死亡复活和重试都是同一个对象。BattleStarted 时清空强化记录。
- **积木实现**：放在 ModKit（DBModKit），DBStudio 的规则引擎也能复用，比如新增"专属技能释放时"触发，以及"改技能参数、再放一次、返还冷却"等动作。
- **代码结构**：新 Mod「Hextech」依赖 ModKit。
  - 生成器写成纯 C#，不碰游戏代码，可以单独测试。
  - 招牌强化每个技能一个文件。
  - DBStudio 调试页加一个"生成预览"：选英雄、填种子，列出各个品质会生成哪些卡，方便调平衡。
- 515"真·鸡舞"不是独立的专属技能，拿到"鸡舞"卡牌后会替换 509，强化跟着 509 走。

## 八、风险

- **生成的卡和技能贴合度不够**：效果大多是"放技能后加点东西"。靠招牌棱彩补；如果第 1 期实测觉得太单调，就提前多写招牌。
- **平衡**：不同技能的冷却、伤害差别很大，靠"按冷却缩放 + 内置冷却 + 参数下限"兜底，第 2 期再按实测调。
- **游戏更新**：生成器只依赖少数几个通用入口（改表、释放事件、`CmdCreateSkill`、buff），比逐个技能打补丁好维护；招牌强化依然要逐个修。
- **强度叠加**：遗物三选一保留，再叠 4 次海克斯，后期容易数值爆炸。先看实测，必要时开了海克斯就用 GameData 的怪物百分比适当提高怪物血量。
- **防篡改**：`nn.fsx()` 会校验金币、三维、刷新次数，所有改动都必须走游戏自己的方法。

## 十、第 1 期实现说明（2026-10-22，和上文不一致的以这里为准）

- **疾风（移速）没做**：游戏加移速的方法是"设成基础值 + a"，不是累加，叠不起来。
- **铁壁改成护甲 +40**：游戏的减伤字段是固定点数，不是百分比。
- **献祭（生命上限 -15%）没做**：第一期棱彩的代价只有沉重、贪婪。
- **"每第 3 次释放"的效果是 ×2**（不是 ×2.5）；触发积木的倍数压低到银 ×1、金 ≤×1.5、棱彩 ≤×2；单次无敌最多 2 秒、返还蓝耗最多 100%。
- **节能和回流不同时出现**（蓝耗已经减到很低时回流等于白给）。
- **参数积木少的技能**（翻滚、形态切换、技能窃取、花式扣篮……）每档多放一块触发效果，保证凑得出三张不同的卡。
