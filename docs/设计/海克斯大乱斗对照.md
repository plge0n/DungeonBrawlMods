# LoL 海克斯大乱斗：设计思路，以及能不能搬进地下城竞技场

> 2026-10-23 整理。资料来源：LoL Wiki `ARAM:_Mayhem` 和 `ARAM:_Mayhem/Augments`、Riot 开发者日志（dev-augmentmaxxing-aram-mayhem）、海斗PRO（haidou.pro，中文名）。
> 大乱斗约有 210 个强化，具体数值以 Wiki 为准。下文中的"本游戏实现"是查反编译代码得出的，**没有实测**。

## 一、大乱斗的设计思路

1. **一局只选 4 次，每次都有分量**。3 级、7 级、11 级、15 级各选一次。次数少，所以每张卡都要能"改变这局怎么玩"，不能只是 +5% 这种小数值。
2. **品质分档，同一次三张同档**。银、金、棱彩三档，同一轮全场拿到的品质相同，前两次不会都是银。品质决定的是"改变打法的程度"：银色多是数值，棱彩改规则。
3. **少量刷新，保留选择感**。每张卡可以单独刷新一次；同一局出现过的卡不再出现。选择的乐趣来自"三选一里的取舍"，不来自无限重抽。
4. **卡写的是"你的某个技能"，没有英雄专属**。大约一半的卡是"技能强化"：卡面写"你的 Q 会……"，选了就套到自己的技能上。同一张卡在不同英雄身上玩法完全不同（「邦！」给内瑟斯就是范围叠层），设计量小，组合多。
5. **触发 > 数值**。大部分卡是"当……时"：击杀时、命中时、放技能时、受伤时、残血时。触发类卡让玩家去追求某种行为（多杀、多放技能），比纯属性有意思。
6. **会成长的卡**。「无限循环往复」「坦克引擎」「超凡邪恶」这类击杀叠层的卡，以及带分段目标的"任务"卡，给后期一个持续的目标。
7. **规则改写放在棱彩**。「亮出你的剑」把远程改近战，「回归基本功」禁用大招换小技能增伤，「玻璃大炮」锁血量换真伤。这些卡把一个英雄变成另一种英雄，是记忆点。
8. **代价换收益**。天体（+生命但 -伤害）、玻璃大炮、不祥契约：强化带明确的缺点，让选择变成取舍。
9. **套装和赛季规则**。曾经有套装（凑 2/3/4 件给阶梯奖励，后来移除），第 3 季每局随机一条"乐队"规则。说明 Riot 也在不断调整这层，不必一开始就做。

## 二、和本游戏的差异

| | 大乱斗 | 地下城竞技场 |
|---|---|---|
| 一局时长 | 15–20 分钟，PvP | 20–50 波，PvE 割草 |
| 技能 | 每个英雄 QWER 四个固定技能 | 一个专属技能（主动或被动）+ 局内学到的技能书 |
| 击杀 | 击杀英雄少而珍贵 | 一波几十上百只小怪，另有变异怪（精英）和 Boss |
| 成长 | 装备 | 属性书、装备、遗物、卡牌、锻造器，数值上限高得多 |
| 选择界面 | 专用界面 | 复用游戏自己的三选一（遗物、技能、锻造都用它） |

所以搬过来时有三条换算规则：
- **"击杀英雄"换成"击杀变异怪 / Boss"**，小怪按"每 N 只算一次"或很低的概率，否则割草游戏里会叠爆。
- **"你的 Q"换成"专属技能"**；需要多个技能的卡（面包三件套）改成"所有主动技能"。
- **大乱斗的百分比数值要压低**，本游戏后期数值本来就高，再叠 4 次海克斯容易爆。用"敌人海克斯"平衡。

### D 搬不过来的

- **召唤师技能**：闪现、雪球、Get Jinxed 系列。本游戏没有召唤师技能。
- **地图和建筑**：草丛、防御塔、男爵、龙魂。
- **装备合成升级**：命运之武、各种"升级 XX 装备"。本游戏的装备系统不同（有锤子强化、妖刀吞装备），可以另外设计，但不是照搬。
- **队友相关**：群抱、全为你、治疗队友。海克斯目前只做单人。
- **符文**：有始有终、交响战歌。

## 四、建议的下一步

1. 第一批实测后，加 B 类里标"好做"的 5–6 张（坦克引擎、果实化、大法师、兴奋、豪猪、双持），通用卡池就够每档 5 张以上。
2. 招牌卡按"玩家最常玩的英雄"排：男枪「大炮」、哥布林之王撕咬的「叠角龙」、炸弹客「核弹」。
3. **代价卡**（天体式"加一样、减一样"）放进棱彩，增加取舍。
4. 套装、任务卡等通用卡有 30 张以上再考虑。
