# 斗魂竞技场（Arena）对照

2026-10-24 调研 LoL Wiki `Arena/Augments`（2026-07，约 230 张）和中文汇总。和[海克斯大乱斗对照](海克斯大乱斗对照.md)互补：斗魂是双人组队模式，**队友协同**类的卡最多，正好补联机。中文名带 * 的是暂译。

## 和大乱斗的差异（对我们有用的）

- 约 25 张队友协同卡，分四种：给队友治疗或护盾、收益共享、看队友状态触发（倒地、残血）、看两人位置（连线、换位）。
- 任务型卡：目标 + 奖励（击杀 N 次拿道具、治疗队友 N 解锁效果）。
- 改抽卡本身的卡：嬗变（给一张高一档的随机卡）、勇者中的勇者（以后都升一档）。
- 重复抽到就升级（Lv1–3）：用户 2026-10-24 决定**不做**，一局 40 波里随机选择已经够多。

## 能用的游戏接口（见 NOTES"联机与队友"）

治疗队友（`yb.iwz`）、周围玩家护盾（`CmdAddNearbyHumanityShield`）、原版 buff（`CmdAddBuff`：技能急速、护甲；圣焰祝福只加持续伤害，普攻和技能不吃）、读队友位置和血量。都不需要队友装 Mod。给队友加任意属性、移动队友、让队友无敌做不了。

## 让经济（本游戏特有，2026-10-24 用户提出）

联机时很多人会把经济让给能 C 的队友。用户定：**辅助者直接指定**要供养的队友（选中供养卡后弹一次选择，只有一个队友时自动选），不做占格子的"核心卡"。
原版能用的：丢金币（扣自己的钱、在地上生成无主金币）、技能急速 buff、队友升级事件；队友的金币不同步给别人，读不到"谁最穷""队友赚了多少"（见 NOTES"联机经济"）。

| 卡 | 效果 | 状态 |
|---|---|---|
| 慷慨供养（银） | 休息时交出 20% 金币，供养的队友脚下掉 1.5 倍 | ✓ 0.5.0 |
| 后排成长（银） | 队友每升一级，你力敏体 +3 | ✓ 0.5.0 |
| 守护之誓（金） | 供养的队友在 15 米内时技能急速 +20 | ✓ 0.5.0 |
| 举国之力（棱彩） | 交出 40% 金币掉 2 倍；供养的队友在 25 米内时技能急速 +40 | ✓ 0.5.0 |
| 借属性 | 原版 CmdChuHeBorrow 能借全队属性 | △ 暂不做 |

搬不过来：召唤师技能、针对敌方英雄的 PvP 卡、经济商店类、地图机制、移动队友或让队友无敌。
