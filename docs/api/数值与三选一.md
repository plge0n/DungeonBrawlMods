# 数值与三选一

## GameData

**用途**：改技能、英雄、怪物配置表里的数值，可以随时整体恢复原版。DBStudio 的数值页和玩法包用的就是它。

```csharp
GameData.Set(DataTable.Skill, "D_Execution", "cd", 5);   // 表、键（技能枚举名 / 英雄编号 / 怪物枚举名）、字段、值
GameData.Active = Multiplayer.GameplayAllowed;            // false 时所有表恢复原版，改动保留
```

`Fields(表)` / `Entries(表)` 列出可改的字段和行，另有 `Original` / `Get` / `IsModified` / `Reset` / `Snapshot` / `Load`。怪物的值是倍率。

**限制**：全局只有一份改动，同一时间只该有一个 Mod 管它（`GameData.Owner`）。两个 Mod 都要改数值时，用 DBStudio 的玩法包统一管理。

只想让怪物整体变强（不改表）时用 `mod.SetEnemyBoost(生命, 攻击, 护盾)`：倍率乘在 GameData 的数值之上，多个 Mod 相乘，
只对之后刷出来的怪生效，卸载时自动撤销（`EnemyBoosts`）。海克斯的"敌人海克斯"用的就是它。
游戏表加载完成（`Ready`）之前设置 `Active = true` 无效。

**联机**：改的是本机的表，会影响队友的体验，必须跟着 `Multiplayer.GameplayAllowed`。

## ChoicePanel / RelicInfo

用游戏自己的三选一界面显示自定义选项（最多 4 个）：

```csharp
ChoicePanel.TryShow("选一个", new[]
{
    new ChoiceOption { Name = "力量", Description = "+20 力量", Quality = 2 },
    new ChoiceOption { Name = "金币", Description = "+100 金币" },
}, i => mod.RunLog.Info("选择", "选了", ("下标", i)));
```

界面忙（`IsBusy`）、不在战斗中时返回 false，过一会儿再试。之后如果游戏在上面打开了自己的选择，游戏会替这次随机选一个，`onPick` 照样会被调用。
`RelicInfo.All` / `Get(编号)` 是遗物列表（含自定义遗物），`Player.GiveRelic` 发放。自己做新遗物见[自定义遗物](遗物.md)。Hextech 是完整的用法示例。
