# 游戏状态

## Game

`Game.LocalPlayer`（不在战斗中为 null）、`InBattle`、`IsSolo`、`IsHost`、`PlayerCount`（只有主机知道，在别人房间里是 -1）、
`Players()`、`Wave`（从 1 开始，和界面一致）、`TotalWaves`、`RelicWaves`、`AutoBattle`、`Localize(键)`。

**联机**：`IsSolo` 只说明房间里有没有别人；改玩法的功能要看 [`Multiplayer.GameplayAllowed`](联机.md)。

## Role / Player

`Role` 是所有角色（敌人、玩家、召唤物）：血量、护盾、位置、体型半径、Boss/精英、召唤物、攻击力和三维、攻速、暴击、护甲、闪避、吸血、
`DistanceTo` / `IsWithin` / `InAttackRangeOf`。

`Player : Role`：蓝量、金币、英雄编号和名字、`Enemies()` / `EnemiesWithin(范围)` / `PickEnemy(范围, 评分)`（分数越低越优先）、
普攻冷却、身上的技能（`FindSkill`、`HeroSkillSlot`、`HasPassive`）。

只能对本地玩家用（走游戏自己的方法，不会触发防篡改校验）：`Heal` `AddMana` `AddGold` `AddStats` `AddAttackSpeed` `AddArmor`
`GiveInvulnerable` `GiveRelic` `FreeCast` `SetPassiveValues`。每次调用都会写一条运行记录。

```csharp
var me = Game.LocalPlayer;
if (me != null && me.HpPercent < 0.3f) me.Heal(me.MaxHp * 0.1);
var boss = me?.PickEnemy(12f, e => e.IsBoss ? 0 : e.DistanceTo(me));
```

**限制**：`Players()`、`Enemies()` 会遍历场景，不要每帧调很多次。临时加成要自己到时间用相反数撤销；下一局英雄重新生成时清零。

## SkillInfo / SkillSlot / SkillBar / HeroSkill

- `SkillInfo`：技能表数据（`Get(编号)`、`Find(枚举名)`、`All()`），名字、标签（`HasTag(SkillTags.Heal)`）、指示器、范围、冷却。
  `Key` 是枚举名，跨版本稳定，适合存档。
- `SkillSlot`：身上的一个技能：剩余冷却、充能、消耗（`CostFor`）、自动释放开关、开关类技能的状态、`ReduceCooldown`、`EstimateDamage`（斩杀类技能）。
- `SkillBar.Buttons()`：技能栏按钮和图标的 `RectTransform`，可以在上面加自己的 UI。
- `HeroSkill.Of(英雄)`：英雄的专属技能（主动或被动）和它的表数据。

## Loot

`Loot.All()`：地上的掉落物（大类、位置、自己能不能捡、占不占背包）。`Loot.TryPick(item)` 替本地玩家拾取，和按 C 一样，范围不超过 5 米，
由服务器确认。还有 `BagCount`、`KeyPickTalisman`。AutoPickup 是完整的用法示例。

## Arena

`Arena.Telegraphs()`：地面预警（圆、扇形、矩形，剩余时间，`Contains(点, 余量)`）；`IsInside`（场地边界）、`FreeDistance`、`ObstacleClearance`（障碍物）。
SmartMove 的躲避就是用它做的。
