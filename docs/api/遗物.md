# 自定义遗物

完整示例：[samples/SkillSample](../../samples/SkillSample) 的铁壁徽章（C#）、[templates/ContentPack](../../templates/ContentPack) 的雷霆之心（内容包）。

## CustomRelics

```csharp
mod.RegisterRelic(new RelicDef
{
    Key = "iron_badge", Name = "铁壁徽章", Description = "护甲 +{0}",
    Icon = "remain_armor",                       // 游戏遗物图标名，或 mod.LoadIcon 返回的名字
    Quality = PassiveQuality.B,
    Values = new[] { 15f }, LevelUp = new[] { 10f },
    Create = () => new IronBadge(),
});

class IronBadge : RelicBehaviour
{
    int added;
    protected override void OnAdded() => Set((int)Value(0));
    protected override void OnLevelChanged(int oldLevel, int newLevel) => Set((int)ValueAt(0, newLevel));
    protected override void OnRemoved() => Set(0);
    void Set(int armor) { Owner?.AddArmor(armor - added); added = armor; }
}
```

注册后和游戏的遗物一样：按品级进遗物三选一（`InPool`）、显示在遗物栏、可以升级（`MaxLevel`，-1 不限）。

- 定义：`Key` `Name` `Description`（`{0}` 由游戏换成数值，含等级成长）`Icon` `Quality` `Values` `LevelUp`
  `ValueTypes`（每个数值的显示方式：Normal / Percent / PercentConst / InversePercent）`MaxLevel` `Unique`（已有就不再出现）`InPool`。
- 行为：`OnAdded` / `OnRemoved` / `OnLevelChanged(旧, 新)` / `OnUpdate` / `OnGameEvent` / `OnHit`；可用 `Owner` `Level` `Value(i)` `ValueAt(i, 等级)`。
- `CustomRelics.Give(info, 等级)` 直接发放，`OnLocalPlayer(info)` 找到身上的实例。`RelicInfo.All` 也会列出自定义遗物。
- 名字和说明的翻译键是 `relic.<Key>.name` / `relic.<Key>.desc`。

## 联机

- 遗物只在自己的客户端生效，别人不用装。不是团队遗物，也没有获取次数上限，所以选遗物时不会给房主发任何消息。
- 算改玩法的内容：`Multiplayer.GameplayAllowed` 为 false 时不进三选一（每次弹出时现算），`Give` 也不给。已经拿到的不会被收回。
- 同步给队友（`CmdUploadSyncPlayerData`）、国王对决、镜像 Boss 的构筑数据会去掉自定义遗物。代价是玩家信息面板和结算界面里也看不到它们，这和自定义技能一样。

## 限制

- 编号由 Mod 的 GUID 和 `Key` 算出（3000000 起），发布后不要改。
- "重试波次"还原时，游戏会在原对象上写回字段、重建遗物列表：本波选的遗物会消失（不会调用 `OnRemoved`，属性由游戏一起还原），
  行为对象里的字段不会还原。
- 王者模式的拟人玩家拿不到自定义遗物（`kingLock`）。
