# 自定义装备

完整示例：[samples/SkillSample](../../samples/SkillSample) 的静电、风暴法杖（C#）、[templates/ContentPack](../../templates/ContentPack) 的同名内容（内容包）。

> 0.24.0 新增，**还没有在游戏里实测过**，接口可能还会调整。

两种用法：给游戏已有的装备追加特效（`CustomEquipEffects`），或者做一件全新的装备（`CustomEquipment`）。

## CustomEquipEffects：装备特效

```csharp
mod.RegisterEquipEffect(new EquipEffectDef
{
    Key = "static_edge", Name = "静电", Description = "命中时回复 {0} 点法力",
    Values = new[] { 3f },
    AttachTo = new[] { 2 },                      // 游戏装备编号：买到 2 号装备时这个特效一起生效
    Create = () => new StaticEdge(),
});

class StaticEdge : EquipEffectBehaviour
{
    float next;
    protected override void OnHit(HitInfo hit)
    {
        if (Time.time < next) return;
        next = Time.time + 0.5f;
        Owner?.AddMana((int)Value(0));
    }
}
```

特效写进游戏的装备特效表，创建、卸下、强化都走游戏自己的流程；装备说明里会多出一行这个特效的说明（`{0}` 换成数值）。和游戏自己的特效一样，说明里不显示特效名字，名字用在伤害统计等地方，所以想让玩家看出是哪个特效，就把关键词写进说明。

- 定义：`Key` `Name` `Description` `Values` `LevelUp`（每强化一级加多少）`AttachTo`（挂到哪些游戏装备上，可以不写）`Create`。
- 行为：`OnAdded`（穿上）/ `OnRemoved`（卖掉、卸下）/ `OnLevelChanged(旧, 新)`（强化）/ `OnUpdate` / `OnGameEvent` / `OnHit`；
  可用 `Owner` `Equipment`（装备编号）`Level` `Value(i)` `ValueAt(i, 等级)`。每件装备一个行为对象，只在本地玩家身上运行。
- `CustomEquipEffects.OnLocalPlayer(info)` 找到身上的行为对象（好几件装备都挂了它时有多个）。
- 名字和说明的翻译键是 `equipEffect.<Key>.name` / `equipEffect.<Key>.desc`。
- 加属性要在 `OnRemoved` 里自己撤销，和遗物一样。

## CustomEquipment：全新装备

```csharp
var charge = mod.RegisterEquipEffect(new EquipEffectDef { Key = "storm_charge", … });
var staff = mod.RegisterEquipment(new EquipmentDef
{
    Key = "storm_staff", Name = "风暴法杖", Description = "雷霆骑士的旧武器",
    Icon = "equip_2",                             // 游戏装备图标名，或 mod.LoadIcon 返回的名字
    Attributes = { ["attack"] = 60, ["hp"] = 200 },
    Effects = { charge },                         // 自己注册的特效
    GameEffects = { "Sputtering" },               // 游戏已有的特效（EquipSkillType 的名字）
    Artifact = true,                              // 进神器三选一
});
CustomEquipment.Give(staff);                      // 直接给本地玩家穿上，装备栏满了返回 false
```

装备写进游戏的装备表，穿上、属性、说明、图标都走游戏自己的流程。

- `Attributes` 的键是装备表的属性名（`hp` `mp` `attack` `attackSpeed` `Armor` `moveSpeed` `STR` `STA` `AGI` `baojilv` `skillDamage` `luck`……），
  完整列表看 `CustomEquipment.AttributeNames`，注册时会检查。值和装备表一样，百分比类写小数（0.1 = 10%）。
- `GameEffects` 的数值照抄游戏里第一件带这个特效的装备。
- 获得方式：`Artifact = true` 时进神器三选一，或者 Mod 自己调 `Give`。**不进商店，也不会掉在地上**。
- `CustomEquipment.CountOnLocalPlayer(info)` 数本地玩家身上有几件。
- 名字和说明的翻译键是 `equip.<Key>.name` / `equip.<Key>.desc`。
- 卸载 Mod（热重载）时本地玩家身上的这件装备会被卸下，特效收到 `OnRemoved`。

## 联机

- 装备和特效只在自己的客户端生效，别人不用装。
- 算改玩法的内容：`Multiplayer.GameplayAllowed` 为 false 时特效不再挂到游戏装备上、自定义装备不进神器三选一，`Give` 也不给。已经穿上的不会被收回。
- 同步给队友、国王对决、镜像 Boss 的构筑数据会去掉自定义装备（不然没装 Mod 的人打开你的构筑面板会出错）。
  代价是队友的构筑面板和结算界面里看不到它，这和自定义技能、遗物一样。挂在游戏装备上的特效本来就不在构筑数据里。
- 别人身上、镜像 Boss 身上的同一件游戏装备也会带上追加的特效，但行为只在本地玩家身上运行，对它们没有效果。

## 限制

- 编号由 Mod 的 GUID 和 `Key` 算出（特效 4000000 起，装备 5000000 起），发布后不要改。
- 自定义装备不能强化，卖出价是游戏的默认价格。
- 王者模式的拟人玩家拿不到自定义特效和装备（`kingLock`）。
- "重试波次"还原时，本波卖掉的装备会回到身上，它的特效重新开始收到事件（不会再调用 `OnAdded`），行为对象里的字段不会还原。
- 注销特效时，已经穿着的装备上会留下一个不起作用的特效对象，直到卖掉。
