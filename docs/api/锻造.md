# 锻造

`Forging.CanOpen` / `Open(ForgeTier)` 打开一次免费锻造，不购买。ForgeTier 为 Normal / Gold / Epic。

`mod.UseForgingChoice(Func<ForgeOffer,int?>)` 注册唯一处理器，遵循 HandlerSlot：先注册优先、设置中可指定、卸载清理。Forging.ChoiceAvailable 表示补丁可用。异常、null 或无效下标保留原界面并记录日志。仅战斗本地玩家；不受玩法握手限制，在打榜模式安装。

```csharp
mod.UseForgingChoice(offer => enabled ? (int?)0 : null);
mod.OnForgingChosen((offer, index) => { /* 原生属性回调成功后，自动和手选均通知 */ });
```

ForgeOffer：Tier、Candidates；ForgeCandidate：Name（游戏显示名）、Quality（0~4 = D/C/B/A/S）、Stats（1~2 项）；ForgeStat：Type（ForgeAttribute）、Value（表内单位，百分比为百分点）、IsPercent。完整枚举见 DBModKit/ForgeOffer.cs。集合只读；通常 3 项，毁灭王座卡为 4，上限不超过候选池大小。

原生界面打开完成后同步走玩家确认内部方法，保留应用属性、关闭、输入/暂停收尾和商店回调。每次打开立即确认，同一调用栈连续锻造不会积压或重复。handler 不应自行打开其他选择面板；原绑定变化时不确认。返回 null 时游戏原本的覆盖待选行为仍适用。

成功通知可统计累计；handler 仅做决策，不应提前累计。原生回调内部异常由游戏捕获，已发生的副作用无法回滚。CheckpointSaved / Restored 可同步局内累计。缺少新成员只停用自动选择。
