# 自动释放、走位与技能调整

## AutoCast

**用途**：接管游戏的"右键技能图标自动释放"。技能冷却好、蓝够时游戏每帧问一次，处理器决定放不放、打谁。

```csharp
mod.UseAutoCast((slot, player) =>
    slot.Info.HasTag(SkillTags.Heal) && player.HpPercent > 0.5f
        ? AutoCastVerdict.Skip("血量充足")
        : AutoCastVerdict.Cast("打血最少的", e => e.Hp));
```

`Vanilla`（不干预）、`Skip`（这一帧不放）、`Cast(原因, 目标评分)`（施法范围内分数最低的敌人）、`CastOnSelf`（无需瞄准的技能不要求附近有敌人）。
`mod.OnAutoCastResolved` 报告结果（`Casted` 为 false 说明游戏没放出去）。

**限制**：同一时间只有一个处理器，后注册的覆盖先注册的（日志里有警告）。SmartSkill 用的就是它。

## MoveControl

`mod.UseMovement(ctx => MoveCommand.Move(方向, "原因"))`：玩家没按方向键时接管走位，等同于按住这个方向键；返回 `MoveCommand.None` 走游戏原版逻辑。
`ctx.InAttack` 时移动会打断普攻。玩家一按方向键就完全听玩家的。同一时间只有一个处理器。

## SkillTuning

`mod.TuneSkill(技能编号, new SkillTune { Damage = 1.2f, Cooldown = 0.8f, Cost = 1f, Duration = 1f, ExtraCharges = 1 })`：只调本地玩家身上的这个技能，
配置表保持原版；多个 Mod 的调整会合在一起。传 `SkillTune.None` 撤销，卸载时自动撤销。Hextech 用它做强化。

**联机**：只影响自己的技能，但改了伤害就算改玩法，要先看 `Multiplayer.GameplayAllowed`。

## SkillTooltips

`mod.SetSkillTooltip(技能编号, "文字")`：在技能悬停提示末尾追加一段，传 null 去掉，卸载时自动去掉。
