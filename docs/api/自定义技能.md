# 自定义技能

完整示例：[samples/SkillSample](../../samples/SkillSample)（被动 + 主动）、[samples/Frieren](../../samples/Frieren)（直线技能）、
[samples/BundleSkill](../../samples/BundleSkill)（图标、特效、动作来自 AssetBundle）。不写代码的写法见[内容包](../内容包.md)。

## PassiveSkills

```csharp
mod.RegisterPassive(new PassiveSkillDef
{
    Key = "blade", Name = "饮血之刃", Description = "力量 +{0}",
    Quality = PassiveQuality.C, Values = new[] { 20f }, LevelUp = new[] { 10f },
    Create = () => new BloodBlade(),
});

class BloodBlade : PassiveSkill
{
    int added;
    protected override void OnAdded() { added = (int)Value(0); Owner?.AddStats(added, 0, 0, 0); }
    protected override void OnRemoved() => Owner?.AddStats(-added, 0, 0, 0);
}
```

注册后和游戏的被动一样：进技能书三选一（`InSkillBook`，按品级分池）、占一个技能格、图鉴里能看到。行为重写 `OnAdded` / `OnRemoved` /
`OnUpdate` / `OnGameEvent` / `OnHit`。`PassiveSkills.Give(info)` 直接发放，`OnLocalPlayer(info)` 找到身上的实例。

## ActiveSkills

```csharp
mod.RegisterSkill(new ActiveSkillDef
{
    Key = "nova", Name = "雷暴", Description = "造成 {0} 点伤害",
    Indicator = SkillIndicator.Range, Cost = 20, Cooldown = 8f, Range = 3f, Duration = 2f,
    DamageBase = 100, DamageValue = 1.5f,
    Create = () => new Nova(),
});

class Nova : ActiveSkill
{
    protected override void OnCast()
    {
        Effect("Effect/SpellThunder", Position, 1.5f);
        PlayAnimation("Frank_RPG_2Hand_Skill01_WhirlWind", 1f, 2f);
        DamageArea(Position, Radius);                // 默认按公式伤害，走游戏的伤害结算
    }
}
```

扣蓝、冷却、充能、瞄准、自动释放都走游戏原来的流程。行为：`OnCast` / `OnUpdate(dt)` / `OnEnd`；可用 `Position` `Direction` `Target` `Radius`
`FormulaDamage` `Remaining` `Caster` `IsMine`，方法 `DamageArea` `Damage(目标)` `Effect` `PlayAnimation` / `StopAnimation`。
直线、扇形等形状自己用 `Game.LocalPlayer.EnemiesWithin` 筛（见 samples/Frieren 的杀人魔法）。

## ModAssets / ModBundle

- `mod.LoadIcon("key", "assets/icon.png")` / `mod.RegisterIcon("key", sprite)` → 图标名，填进 `Icon`。
- `mod.LoadBundle("assets/x.bundle")` → `ModBundle`（`Sprite` `Prefab` `Clip` `Load<T>` `AssetNames`），卸载时自动关包。
- `mod.RegisterEffect("key", 预制体)` → 特效路径，传给 `Effect`，走游戏的对象池。
- 打包方法见 [AssetBundle](../AssetBundle.md)。

## 联机

- 被动只在自己的客户端运行，别人不用装。
- 主动技能在每个装了这个 Mod 的客户端上都会创建（特效大家都看得到），伤害只在施法者那边结算（`IsMine`）；没装的人只看到施法动作，不会出错。
- 都算改玩法的内容：`Multiplayer.GameplayAllowed` 为 false 时不进技能书，`Give` 也不给。
- 同步给队友、上传国王对决、镜像 Boss 的构筑数据会去掉自定义技能。

## 限制

- 编号由 Mod 的 GUID 和 `Key` 算出（被动 1000000 起、主动 2000000 起）：发布后不要改 GUID 和 Key。
- "重试波次"会把玩家属性还原到波次开始时，但不会还原行为对象里的字段（比如上面记下的 `added`）。
