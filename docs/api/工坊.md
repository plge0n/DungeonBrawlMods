# 创意工坊与内容包

## Workshop（插件条目）

游戏的工坊不加载 dll。ModKit 自带加载器：订阅的条目根目录有 `dbmod.json` 且 `"Type": "plugin"` 时，当成 BepInEx 插件加载，
第一次加载前弹窗让玩家确认（工坊 dll 就是别人写的程序）。

```json
{ "Format": 1, "Type": "plugin", "Name": "SmartSkill", "Version": "0.7.0", "MinModKit": "0.9.0", "Assemblies": ["SmartSkill.dll"] }
```

- 本地测试：条目文件夹放进 `BepInEx/workshop-dev/`（不用确认），并挪走 `plugins` / `scripts` 里的同名插件（本地已装的优先）。
- `pack.ps1` 在 `dist/workshop/` 生成条目，`tools/WorkshopUpload` 上传。条目里不要放 `manifest.json`（那是游戏自己的格式）。
- `Workshop.Items` 列出条目和状态，`Decide(item, 允许)` 改玩家的选择。
- `Dependencies` 写依赖的插件（GUID、最低版本、工坊物品号），缺了不加载并提示，见[依赖和冲突](依赖和冲突.md)。

## ContentPacks（内容包）

`"Type": "content"` 的条目是不含代码的内容包：JSON 定义技能、被动、变体英雄，不用确认。也可以放在 `BepInEx/content/<名字>/`。
写法见[内容包](../内容包.md)，示例在 [templates/ContentPack](../../templates/ContentPack)。

`ContentPacks.All` 列出包（`Loaded`、`Summary`、`Errors`），`SetEnabled(pack, 开关)` 开关（战斗中不能切换）。
