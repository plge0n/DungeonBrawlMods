# 联机

游戏不检查 Mod，装了和没装的人能同房间玩，伤害由各自的客户端计算。所以：

- **不能**注册自定义 Mirror 消息：没装 Mod 的人收到不认识的消息会断线。要交换数据只能用 Steam 大厅成员数据（`LobbySync`）。
- 改玩法的功能看 `Multiplayer.GameplayAllowed`，不要自己判断 `Game.IsSolo`。

## Multiplayer

装了 ModKit 的玩家每秒公布自己的 ModKit 版本和改玩法的内容（"GUID@版本#指纹"），据此得出 `Policy`：

| Policy | 什么时候 | GameplayAllowed |
|---|---|---|
| `Solo` | 房间里只有自己 | 是 |
| `AllHaveSame` | Steam 大厅里每个人装的都一样 | 是 |
| `HostAllowed` | 有人装的不一样，但房主在 Mod 设置里勾了"在这个房间里允许"（换房间自动取消），装了 ModKit 的人都会收到提示 | 是 |
| `Blocked` | 其他情况，包括局域网联机（没有大厅，确认不了） | 否 |

进入战斗时锁定，这一局只会收紧不会放宽。`Status` 是给玩家看的说明，`Changed` 在策略变化时触发。

战斗中降级（比如房主取消允许、有人改了玩法包）只挡住**之后**的改玩法内容：技能书、遗物和神器三选一里不再出现自定义内容、装备特效不再挂到游戏装备上，玩法包停用、数值恢复原版。
**已经拿到的不收回**（开局时生效的变体属性和专属技能、已学的自定义技能、已选的遗物）：进地牢后房间不能再进人，战斗中降级很少见，
中途撤掉会让英雄属性突然变化。

**哪些算改玩法的内容**：自定义被动、主动技能、遗物、装备和装备特效、改了属性或专属技能的变体英雄、内容包里的这些（ModKit 自动计入），
以及调用了 `mod.DeclareGameplay(指纹)` 的 Mod。指纹用来区分同一个 Mod 的不同设置（比如 DBStudio 玩法包内容的哈希）；
功能关掉时调 `mod.RetractGameplay()`。只换外观的（皮肤、变体的模型和名字）不受限制。

```csharp
mod.OnUpdate(() =>
{
    if (Plugin.Enabled.Value) mod.DeclareGameplay(); else mod.RetractGameplay();
    featureActive = Plugin.Enabled.Value && Multiplayer.GameplayAllowed;
});
```

**限制**：握手结果只决定本机启不启用；没装 ModKit 的人收不到任何提示。别人公布的内容可以造假，后果只影响造假的人自己那边。

## LobbySync

`LobbySync.Publish("dbmods.<mod名>", 文字)` 写自己的一条，`LobbySync.Read(键)` 读其他人的（不含自己）。

- 只有 Steam 联机有大厅（进地牢后也不离开）；局域网和单机时读写都什么也不做（`InLobby`）。
- 值最长约 8KB；Steam 会把每次修改广播给所有人，隔一两秒写一次，不要每帧写。
- 别人写的内容不可信：解析时检查格式和范围，不能拿来改游戏。
- 键加上 Mod 名前缀，避免和别的 Mod 撞。DamageMeter（队友伤害）和皮肤同步都用它。
