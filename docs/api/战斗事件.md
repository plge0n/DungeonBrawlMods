# 战斗事件

## GameEvents

`mod.OnGameEvent(e => …)`：本地玩家相关的事件。`e.Kind`：`EnemyKilled`（`Target`、`IsBoss`、`IsElite`）、`SkillCast`（`Skill`）、
`Critical`（`Amount`）、`Dodged`、`Damaged`（`Amount` = 掉的血，同一帧的多次伤害合成一次）、`LevelUp`、`Revived`、`ItemPicked`（`ItemId`）、
`WaveStarted` / `WaveEnded`（`Wave`）、`BossAppeared`、`GameOver`。

```csharp
mod.OnGameEvent(e =>
{
    if (e.Kind == GameEventKind.EnemyKilled && e.IsBoss) Game.LocalPlayer?.AddGold(50);
});
```

**联机**：游戏的这些回调只在本地玩家的客户端触发，所以只有自己的事件。
**限制**：波次事件靠额外的钩子，`GameEvents.WaveEventsAvailable` 为 false 时收不到。

## Combat

- `mod.OnHit(hit => …)`：本机造成的每次命中。`Damage`（含打掉的护盾）、`Target`、`Source`、`Critical`、`IsNormalAttack`、`Lethal`（这一下打死了）、
  `SkillId`（主动释放的技能）、`SourceSkillId`（造成伤害的技能实例，覆盖更全）、`EffectKind` / `EffectName`（被动、装备、遗物、Buff）、`Type`、`Origin`。
- `mod.OnSkillCast(cast => …)`：本地玩家放技能（`SkillId`、`Position`、`Rotation`、`TargetId`、`IsFree`）。可以用 `player.FreeCast(cast)` 免费再放一次，
  注意别无限连锁（`IsFree` 为 true 时不要再触发）。

```csharp
mod.OnHit(hit =>
{
    if (hit.Lethal && hit.Target.IsElite) mod.RunLog.Info("击杀", "精英", ("技能", hit.SourceSkillId));
});
```

**限制**：命中事件很频繁，处理器里不要做重活。DamageMeter 是完整的用法示例。
