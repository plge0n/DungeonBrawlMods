# 生命周期与基础设施

## ModContext

**用途**：一个 Mod 的运行上下文。通过它订阅的事件、注册的技能、打开的配置都会在卸载时自动清理，所以 Mod 可以用 ScriptEngine 热重载。

```csharp
[BepInPlugin(Guid, Name, Version)]
[BepInDependency(ModKitPlugin.Guid, "0.21.0")]
public class Plugin : BaseUnityPlugin          // 必须直接继承 BaseUnityPlugin，不能继承 ModKit 里的类
{
    private ModContext mod;
    private void Awake() => mod = ModContext.Start(this, Logger, OnLoad, OnUnload);
    private void OnDestroy() => mod?.Dispose();

    private void OnLoad(ModContext mod)
    {
        mod.OnUpdate(Tick);                                   // 每帧
        mod.OnBattleStarted(() => mod.RunLog.Info("战斗", "开始"));
        var config = mod.LoadJson<MySettings>("MyMod.json");
        mod.AddSettings("我的设置", BuildUi);                  // DBStudio 的 Mod 页
    }

    private void OnUnload() { }                               // 只销毁自己挂在游戏对象上的东西
}
```

常用方法：`OnUpdate` `OnBattleStarted` `OnBattleEnded` `OnQuitting` `OnGameEvent` `OnHit` `OnSkillCast` `OnCheckpointSaved/Restored`
`UseAutoCast` `UseMovement` `TuneSkill` `SetSkillTooltip` `LoadJson` `AddSettings` `RegisterPassive` `RegisterSkill` `RegisterHeroVariant`
`LoadIcon` `RegisterIcon` `RegisterEffect` `LoadBundle` `DeclareGameplay` `AddCleanup`；属性 `Folder`（插件文件夹）`Text` `RunLog` `Metadata`。

**限制**：`onLoad` 抛异常时 Mod 不启动，已注册的会被清理。自己 `new` 的 GameObject、挂在游戏 UI 上的按钮要在 `onUnload` 里销毁。

## ModEvents

`Update`、`BattleStarted`（本地玩家出现）、`BattleEnded`、`Quitting`、`CheckpointSaved` / `CheckpointRestored`（重试波次的快照和还原：
游戏只还原它自己的对象，Mod 的状态要自己存一份）。用 `ModContext` 的同名方法订阅，卸载时自动退订。

## JsonConfig&lt;T&gt;

`BepInEx/config/<文件名>` 下的 JSON 配置。`Data` 是对象，改完调 `MarkDirty()`，一秒后自动保存，退出时也会保存。
简单的开关用 BepInEx 的 `Config.Bind`（DBStudio 的 Mod 页会自动列出）；列表、字典这类结构化数据用 JsonConfig。

## ModSettings

`mod.AddSettings(标题, build, refresh)` 在 DBStudio 的 Mod 页里挂一块自定义设置。`build(container)` 往竖向布局里加 `NativeUi` 控件，
每次显示都会重新调用；`refresh` 在显示期间每秒调几次，用来刷新状态文字。没装 DBStudio 时不显示，也不会出错。

## RunLog

所有 Mod 共用的结构化日志，写进 `BepInEx/DBModKit/trace.log`（上一次启动的在 `trace.prev.log`）。

```csharp
mod.RunLog.Info("规则", "触发了", ("生命", player.Hp), ("目标", "Boss"));
mod.RunLog.Debug("躲避", "换落脚点");     // 高频细节用 Debug，默认不进文件
```

ModKit 自己会记 Mod 加载、进出战斗、房间人数、联机策略、`Player` 的回血/加蓝/改属性（前后数值和调用它的 Mod）等，Mod 只需要记"为什么这么做"。
测试时把 DBModKit 的 `FileLevel` 改成 `Debug`，按 Ctrl+F10 加标记；DBStudio 调试页的"导出"会生成诊断报告。

## ModText / Localization

代码里写中文原文当默认值，翻译放在插件旁边的 `lang/<语言>.json`（平铺键值）：

```csharp
NativeUi.Label(parent, mod.Text["debug.title", "调试"]);
mod.Text.Format("rule.fired", "规则「{0}」触发", rule.Name);
```

语言跟随游戏设置，换语言时触发 `Localization.Changed`。查找顺序：当前语言 → 英文（游戏不是中文时）→ 代码里的中文。
自定义技能的名字和说明也走这里（键 `skill.<Key>.name` 等）。

## ScreenNotice

`ScreenNotice.Show("文字", 秒数)`：屏幕顶部的临时提示。同一时间只显示一条，后来的覆盖前面的。ModKit 不兼容时也能用。
