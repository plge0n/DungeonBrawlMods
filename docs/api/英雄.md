# 英雄

## HeroVariants（变体英雄）

**用途**：做"新英雄"的推荐做法。底层仍是游戏已有的英雄，出生时换属性、专属技能、模型和名字，所以联机、存档、图鉴、成就都按原英雄走。

```csharp
var mana = mod.RegisterPassive(new PassiveSkillDef { Key = "infinite_mana", Name = "无限魔力", InSkillBook = false, Create = () => new InfiniteMana() });
mod.RegisterHeroVariant(new HeroVariantDef
{
    Key = "frieren", Name = "芙莉莲", BaseHero = 20,       // 精灵魔法使
    PassiveSkill = mana,
    WorkshopModel = 3798456516,                           // 工坊里的芙莉莲模型（manifest 的 heroId 要等于 BaseHero）
});
```

完整示例：[samples/Frieren](../../samples/Frieren)。

- 属性：`Strength` `Agility` `Stamina` 及成长、`Attack` `Armor` `Hp` `Mp` `HpRecover` `MpRecover` `MoveSpeed` `AttackSpeed`，为 null 时用原英雄的。
- 专属技能四选一：`ActiveSkill` / `PassiveSkill`（自己注册的）、`GameActiveSkill` / `GamePassiveSkill`（游戏编号）。
- 模型：`ModelFolder`（Mod 自带，格式同工坊英雄模型）或 `WorkshopModel`（工坊物品号，要玩家自己订阅；没订阅时显示原版模型）。
- 玩家在 Mod 设置 → DBModKit → 英雄变体里选；Mod 也可以 `HeroVariants.Select(英雄, 变体)`。`LocalVariant` / `LocalGameplayActive` 是这一局的情况。

**联机**：属性和专属技能只在 `Multiplayer.GameplayAllowed` 时生效，否则只换名字和模型。模型只在自己这边显示，没装 Mod 的人看到原英雄。

## HeroSkins

给每个英雄选一套工坊或本地（`BepInEx/skins/`）的模型：`HeroSkins.Scan()` 列出可用的，`Set(英雄, 皮肤编号)` 选择。
`OnlyLocalPlayer`（只换自己的）、`SyncInLobby`（Steam 联机时通过大厅成员数据告诉队友，队友也订阅了才看得到）。DBStudio 的皮肤页是完整的界面。

**限制**：不会替别人订阅工坊物品，`OpenWorkshopPage` 只打开页面。局域网不同步。
