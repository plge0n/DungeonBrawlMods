# 界面

## NativeUi

用游戏自己的素材（面板、方框、勾选、齿轮、关闭按钮、字体）拼界面，风格和游戏一致。先调 `NativeUi.Load()`（素材还没加载时返回 false）。

- 布局：`Row`、`Column`、`ScrollView`、`Panel`
- 控件：`Label`、`Toggle`、`Slider`、`Dropdown`、`Button`、`IconButton`、`Input`（输入框）
- 窗口：`Overlay(名字, 层级)` 建一个顶层 Canvas，`Window(父节点, 标题, 尺寸, 关闭回调)` 居中的大窗口（`Body` `Header` `Status`），`Tabs` 页签
- 颜色：`Gold`、`TextColor`、`DimText`

```csharp
var canvas = NativeUi.Overlay("MyMod", 5000);
NativeWindow window = null;
window = NativeUi.Window(canvas.transform, "我的窗口", new Vector2(900f, 600f), () => window.Destroy());
NativeUi.Toggle(window.Body, "启用", 300f, on => Plugin.Enabled.Value = on);
```

在 `ModSettings` 的 `build` 回调里拿到的 container 已经有竖向布局，直接往里加控件即可。

## GameInput / GamePause

打开自己的窗口时：`var block = GameInput.Block();` 屏蔽游戏的键鼠输入，`var pause = GamePause.Acquire();` 暂停游戏，关窗口时 `Dispose()`。
可以叠加，全部释放后才恢复。**联机时不要暂停**（只会暂停自己这边）。

## NativeTip

`NativeTip.Show(标题, 文字, 图标路径, 位置, 品质)` / `Hide()`：游戏原生的悬停提示框。

**限制**：自己创建的 UI 对象要在 `onUnload` 里销毁，否则热重载后会留下一份旧的。

## ModList

`ModList.Plugins()`：BepInEx 已加载的插件（含 ScriptEngine 热重载的和工坊插件）和状态（`ModState`：已启动、不用 ModKit、ModKit 不兼容、启动出错），
`LoadErrors` 是 BepInEx 没能加载的插件，`ProblemCount()` 是需要玩家注意的问题数。主菜单的"Mod"按钮打开的列表就是用它做的。
