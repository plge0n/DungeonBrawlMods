# SmartSkill 更新日志

## 0.6.0
- 新条件：自身血量 ≥、没有 Boss、有敌人血量 ≤ X%、能斩杀的敌人 ≥ N（处决、点金术、撕咬）、上一次的效果结束后再放、保留充能
- 斩杀判断用实际命中自动校准，弹窗里显示命中/斩杀次数和校准系数
- 开关技能（献祭等）：条件满足时保持开启，不满足时自动关闭（原版会反复开关）
- 选目标时把无敌的敌人排到最后；勾了斩杀或低血量条件时优先打符合的敌人
- "按标签推荐"新增斩杀类、开关类、PayToWin、增益/变身类的推荐
- 需要 DBModKit 0.3.0

## 0.5.1
- 改用 `ModContext`，卸载时移除齿轮和弹窗，支持热重载
- 需要 DBModKit 0.2.0

## 0.5.0
- 改为依赖 DBModKit，本身不再引用游戏代码；游戏更新后只需更新 DBModKit
- 插件 GUID 改为 plge0n.dungeonbrawl.smartskill（配置文件名随之变为 plge0n.dungeonbrawl.smartskill.cfg）

## 0.4.0
- 删除 F8 设置窗口，统一使用技能图标上的齿轮弹窗
- 启动时检查游戏版本和依赖的游戏成员，不兼容时自动停用并在屏幕上提示
- 详细日志默认关闭
- 新增打包脚本，生成「完整包」和「仅插件」两种发布包

## 0.3.0
- 技能图标右上角的齿轮 + 原生风格设置弹窗

## 0.2.0
- 每个技能单独设定释放条件（原版 / 自定义 / 永不），取代写死的规则

## 0.1.0
- 首个版本：按技能标签写死的治疗、护盾、留蓝等规则
