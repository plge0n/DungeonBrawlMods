# DBStudio changelog (English)

## 0.40.0

- Updated the Mod page's leaderboard guidance: whitelisted mods can upload scores with the game author's approval. Having DBStudio loaded blocks uploads; enable Ranked Mode in the main-menu Mod window and restart to disable it. Turn the mode off and restart to restore it.
- Requires DBModKit 0.40.0. The new leaderboard rules and mode switching have not been play-tested.

## 0.39.0

- Added the Build page after Debug. During single-player combat, add, replace or remove skills, add or remove passives, and adjust equipment and relic levels. Lists show icons, localized names and levels. Actions appear in the event log.
- The card section provides a runtime unlock, off by default, that restores the original collection, deck and presets when disabled. Toggling during combat affects the next run.
- Permanent save writing requires confirmation and creates a backup first. The result persists after uninstalling and is synced by Steam Cloud. Recovery requires the backup.
- Requires DBModKit 0.39.0. Passives support adding and removing only.

## 0.10.0
- Gameplay packs follow ModKit's multiplayer handshake: they apply when you're alone, when everyone has exactly the same mods and packs, or when the host allows it
- The Mod page shows whether gameplay content is currently enabled
