地下城竞技场 Mod 运行环境（BepInEx + DBModKit）
Dungeon Brawl Mod Runtime (BepInEx + DBModKit)

【安装】
1. 订阅后等 Steam 下载完成。
2. 退出游戏，双击本文件夹里的 install.bat。
   本文件夹位置：<Steam 库>\steamapps\workshop\content\4246640\<条目号>\
3. 启动游戏。第一次启动会慢一点。
条目更新后游戏里会提示，退出游戏再运行一次 install.bat 即可。

【卸载】
运行 uninstall.bat，再在创意工坊取消订阅。BepInEx 文件夹（含设置）会保留，不需要可以手动删除。

【说明】
- 游戏的创意工坊不会自动加载代码 Mod，所以需要运行一次安装器，把加载器放进游戏目录。
- 按游戏作者的规则，装了 Mod 后成绩不会上传排行榜，其他功能不受影响。想冲榜请先卸载。
- 第三方组件和许可证见 licenses 文件夹。

[Install]
1. Subscribe and wait for Steam to finish downloading.
2. Quit the game and double-click install.bat in this folder:
   <Steam library>\steamapps\workshop\content\4246640\<item id>\
3. Start the game. The first launch takes a bit longer.
When this item updates, the game will tell you; quit and run install.bat again.

[Uninstall]
Run uninstall.bat, then unsubscribe. The BepInEx folder (with settings) is kept; delete it manually if you like.

[Notes]
- The game's Workshop does not load code mods by itself, so the installer puts the loader into the game folder once.
- By the game author's rule, scores are not uploaded to the leaderboard while mods are installed.
- Third-party components and licenses: see the licenses folder.
